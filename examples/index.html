Interfaces with a little dust on them.

Chalkably keeps controls semantic and practical, then gives them the loose edge of a hand-marked board. Seven zero-runtime-dependency attachers, seeded SVG geometry, and motion that knows when to stop.

Made for the parts people actually use

Chalkably is deliberately small. You get a button, card, checkbox, radio, toggle, divider, and input — each backed by native HTML and a decorative SVG sketch. Give it a stable seed for visual tests, let it redraw when a surface changes, or leave the defaults alone and accept a different little mark on every mount. The long copy here is intentional: readable text should still feel calm when the surrounding edges are loose.

Vanilla

import { chalkablyButton } from "chalkably";
import "chalkably/style.css";

chalkablyButton(button, {
  variant: "solid",
  state: "success",
});

React

import { ChalkablyButton } from "chalkably/react";

<ChalkablyButton
  variant={"solid"}
  state={saving ? "loading" : "idle"}
>Save changes</ChalkablyButton>
