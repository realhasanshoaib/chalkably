# Changelog

## 0.1.0 — 2026-08-16

- Forked the component library as Chalkably with chalk-first naming and
  `--chalkably-*` theming.
- Added deterministic core, powder, and soft-edge marks so every seeded SVG
  stroke has uneven chalk density without a runtime dependency.
- Added the optional Cosmic Chalk theme and applied its midnight board,
  moon chalk, comet focus, and constellation accents across the demo.
- Documented the seven vanilla attachers and matching React components.
- Added a responsive deep-slate demo covering every control and button state.
- Reworked the bundled SVG previews to show warm chalk on a dark board.
